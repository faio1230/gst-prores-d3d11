# DX11 ProRes採用判断サマリー（2026-09-25）

結論：**RTX 3070／GStreamer 1.28.2で本goalのM0～M5と指定された最終実表示ゲートを完了**。通常経路は純粋DX11 Compute ShaderによるProRes復号と`GstD3D11Memory`出力で、Vulkan/CPUへの暗黙fallbackはない。M5までの色タグ・端数寸法・途中の寸法／形式変更、固定SDK CPU基準のYUV全画素最大差1 code・alpha差0、HQ direct性能の−3%ゲートも通過した。修正した実表示手順では、8試行・150有効周回・decoder入力56,340枚でQoS欠落0。これは指定環境・素材・有効周回での判定であり、他GPU、device lost、HDRのRGB数値精度、OS/DWM表示、外部配布まで保証しない。

OSS公開前の追加回帰ではIDCTを上限内の2次元Dispatchに変更し、matrix=0/2のYUV出力、ジョブ表upload前例外からのseek復帰、4:2:2の左寄せクロマを修正した。現行の左寄せRGBは32素材1,859枚で独立BT.709式との差最大1 code、係数不一致0、公開HQ779枚・ASan24,000件・EOS/seekを通過。HQ direct旧M5版比は1080p −0.12%／4K −0.24%で−3%ゲート内。判定値とdebug layer未導入などの限界は[OSS公開前修正](OSS公開前修正.md)に分離した。前記の実表示値はこの変更後に再測定した値ではない。
