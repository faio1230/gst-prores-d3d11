# DX11 ProRes採用判断サマリー（2026-09-23）

結論：**現時点で製品採用は保留**。限定対象の純粋DX11復号とD3D11Memory出力は成立し、実素材の画素精度も測定済み。ただし実表示ではend-to-end欠落とOS未表示が再現する。これは「検証データが揃った」という判断と、「最終製品として完成した」という判断を分けた記録である。Vulkan版へ切り替えていない。

| 検証項目 | 実測結果 | 判断 |
|---|---|---|
| 実素材YUV、固定FFmpeg CPU対DX11 | 公式Proton 1080p50全50枚、DJI 4K24全129枚、DJI 4K60全480枚。Y/U/V全画素の最大絶対差は各1 code。4K60のMAEは0.03529/0.02739/0.02827 | 対象素材で数値検証済み |
| GStreamer専用DX11 RGB10A2 D3D11Memory対独立BT.709式 | 同じ全50/129/480枚を全画素比較。R/G/B最大差各1、Aは0。4K60のMAEは0.03104/0.03119/0.03134、差分sample数は123586193/124172871/124757108 | 明示条件の数値検証済み。撮影時の色意図の保証ではない |

RGB基準はBT.709 limited YUV、BT.709 matrix・transfer・primaries、水平中央クロマからfull-range RGB10A2への変換であり、最終10bit丸めの1 codeを数値許容差とした。素材のchroma locationは未指定なので、製品側のクロマ位置・許容値の合意は残る。GPU値とCPU `videoconvert` 値には丸め・実装の系統差もある。

測定環境はRTX 3070、GStreamer 1.28.2、60 Hz画面。CPU参照はリポジトリ内固定SDK `tools/ffmpeg-n8.1-latest-win64-lgpl-shared-8.1/bin/ffmpeg.exe`。公開素材の出所、色メタデータ、SHA256、比較範囲、再現コマンド、試行別ログは[実素材と表示検証](実素材と表示検証.md)を参照。主要集計は `results/proton-real-yuv.json`、`results/dji-real-4k-yuv.json`、`results/dji-real-4k60-yuv.json`、対応する `*-rgb-element-formula.json`／`dji-real-4k60-rgb-formula.json`、`results/d3d11-display-native-rgb-1080-summary.json`、`results/d3d11-display-native-rgb-4k-summary.json`、`results/presentmon-1080p60-qpc-summary.json`、`results/dji-real-4k60-display-summary.json`、`results/dji-real-4k60-etw-repeat-*.json`。回帰検査は `results/verification-reference-stress-dx11.log` と `results/verification-reference-stress-plugin.log` に保存済み。

次は診断用`Present(1)`経路と現行`Present(0)`を同条件で交互反復し、DXGI／DWMイベントをPTS別に照合する。decoder QoS欠落、sink待ち、OS未表示を別々に減らし、実写4K60でend-to-end 0欠落と短い最大表示間隔を両立させる。その後に他GPU、device lost、動的caps、多入力実表示を採用ゲートとして確認する。これらが済むまで最終目標の完了・製品採用とはしない。
