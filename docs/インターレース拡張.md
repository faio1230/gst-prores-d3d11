# M4：インターレース拡張（採用）

2026-09-24時点。対象は独立したGStreamer用DX11 ProResプラグインであり、外部アプリの再生制御は対象外。FFmpeg n8.1の[ProRes picture/field処理](https://github.com/FFmpeg/FFmpeg/blob/n8.1/libavcodec/proresdec.c)と[インターレース逆スキャン表](https://github.com/FFmpeg/FFmpeg/blob/n8.1/libavcodec/proresdata.c)を基準にした。1 packet内の2 pictureを順に解析し、フィールド局所行をTFFなら偶数→奇数、BFFなら奇数→偶数の行へGPUで書く。YUV係数は専用の逆スキャン表、アルファも同じフィールド配置を使う。VLDの3面非同期リングは変更せず、通常出力のCPU画像読戻しも追加していない。

`proresd3d11dec`は`video/x-raw(memory:D3D11Memory)`の`interlace-mode=interleaved`と`field-order=top-field-first`/`bottom-field-first`を出す。バッファにもINTERLACED/TFF旗を付ける。`proresd3d11rgb`はデインターレースやフィールド対応RGB変換を行わず、インターレース入力を拒否する。独立パイプラインで`not-negotiated`を確認した。RGB経由の最終表示では別途表示可能な経路の指定が必要で、現時点でその経路は採用していない。

固定SDKで作ったapch TFF/BFFとap4h 444 alpha16 TFF/BFFの320×180各2枚を、GPU係数・全画素・capsで確認した。係数完全一致、YUV最大1 code、alpha差0。各形式の1080p30×30枚と4K60×60枚も固定SDK `prores_ks`で生成し、全360枚をDX11/CPUで全画素比較した。YUV最大1 code、alpha差0。製品VLD CSOで全360枚に加え`frame_type=3`の2枚を検査し、計5,640,437,760係数がCPU参照と完全一致した。固定SDK Vulkan GPU経路でも長尺8素材の全360枚を読戻しまで完走した。SHA256は`results/m4-long-coefficients-2026-09-24/summary.json`、比較は`results/m4-long-comparison-2026-09-24`、Vulkanは`results/m4-vulkan-2026-09-24/summary.json`。内部D3D11Memory・field-order・バッファ旗・EOSの4条件と既存HQ破損/seek回帰は`results/m4-smoke-interlace.log`。

FFmpeg n8.1は`frame_type=3`をBFFとして扱い、固定SDK Vulkanでも2/2枚GPU復号した。この値はM0表のTFF/BFFだけでは漏れるため、DX11もBFFとして受理して全係数・画素を検査した。再現は`scripts/probe-prores-m4-fieldtype3.ps1`。ただしこれはBFF packetのheaderだけを変更した合成変異で、カメラ実例を示さない。

独立した公開素材として[SynQRの1080i ProRes 422配布ページ](https://synqr.app/downloads)から30fps版をローカル取得した。ZIP SHA256 `0edfcaab13624dadae973f29fbd5b747ae424b6556649ccdf8b19e2da2ba2844`、MOV SHA256 `e7097473b1e7840c221647c268311894364e1c12ea616aade4aa3987d6d115b1`。apcn、1920×1080、TFF、BT.709、1398枚。固定SDK CPUとの全画素比較は1398/1398枚・YUV最大1 code、Vulkan GPU読戻しも1398/1398枚通過。先頭フレームのGPU係数4,177,920個は完全一致。`results/m4-public-synqr-compact-2026-09-24.json`、`results/m4-public-synqr-vulkan.log`、`results/m4-public-synqr-first-coeff.json`。配布ページに再配布ライセンスの明記を確認できないためMOV/ZIPはコミットしない。これは独立制作の同期テスト映像であり、カメラ実写とは数えない。

追加回帰はASan変異16,000件（旧4素材＋M4のTFF/BFF/alpha4素材）、M2の18素材780枚、M3のアルファ24条件48枚を通過した。TFF/BFFの4種×30枚ではD3D11Memory、EOS/seek、field-order、バッファ旗を確認し、2枚目のpicture header破損は`STREAM/FORMAT`で停止した。行によって値が変わるalpha素材もTFF/BFF各2枚を追加し、alpha値48〜4047、GPU alpha差0、YUV最大1、GPU係数完全一致を確認した。根拠は`results/m4-parser-asan-rerun-2026-09-24/summary.json`、`results/m4-m2-regression-2026-09-24/summary.json`、`results/m4-m3-alpha-regression-2026-09-24/summary.json`、`results/m4-smoke-interlace-negative.log`、`results/m4-varying-alpha-2026-09-24/summary.json`。

最初のHQ direct交互4組はM3版比で1080p −3.95%、4K −4.24%となり−3%ゲート未達だった（`results/m4-hq-direct-ab-2026-09-24/summary.json`）。IDCTのfield情報を既存`destination_y`のbit16と共通`mode`のbit1に符号化し、`IdctBlockJob`を32 byteから旧24 byteへ戻した。VLDの3面リング・同期方式は不変。再測定のM3版→M4版は1080p 444.80→435.97 fps（−1.99%）、4K 260.38→257.51 fps（−1.10%）で両方通過（`results/m4-hq-direct-ab-compact-2026-09-24/summary.json`）。低下原因を転送量と断定はしない。

最終24 byte版は製品CSOでTFF/BFFと`frame_type=3`計362枚・5,640,437,760係数が完全一致、GPU IDCT差最大1（`results/m4-long-coefficients-compact-2026-09-24/summary.json`）。D3D11Memoryの全画素比較は合成8素材360枚でYUV最大1・alpha差0、公開1080iの1398枚も最大1（`results/m4-long-comparison-compact-2026-09-24`、`results/m4-public-synqr-compact-2026-09-24.json`）。旧M1の422 11素材420枚、M2の18素材780枚、M3 alphaの24条件48枚も再走査して最大1・alpha差0。公開HQ779枚のD3D11Memory/EOS、M2の18素材のEOS/seek/RGB寿命、M4のスモーク17破損例と4フィールド例を通過した。結果は`results/m4-m1-regression-compact-2026-09-24/summary.json`、`results/m4-m2-regression-compact-2026-09-24/summary.json`、`results/m4-m3-alpha-regression-compact-2026-09-24/summary.json`、`results/m4-hq-public-compact-2026-09-24/summary.json`、`results/m4-m2-lifecycle-compact-2026-09-24/summary.json`、`results/m4-compact-idct-smoke.log`。

新形式8素材のDX11 direct中央値は1080pで159.53～380.44 fps、4Kで83.39～222.85 fps。全4K条件が60 fps以上（`results/m4-direct-performance-compact-2026-09-24/summary.json`）。固定SDK Vulkanは同一RTX 3070で各形式をGPU wrapped／GPU読戻し各3回測定し、完了試行は指定枚数・エラー0。48試行中3試行はタイムアウトまたは復号エラーで1回再試行した。最初の`-stream_loop`測定は繰り返し境界で停止したため無効とし、1周・起動込み、20秒タイムアウトで取り直した。Vulkanの4K読戻し中央値の最低は85.96 fps。DX11 directとは境界が異なり比率では判定しない（`results/m4-vulkan-performance-timed-2026-09-24/summary.json`）。

最終24 byte版のASanは旧4素材と新4素材の計8 seed・16,000件を通過した（`results/m4-parser-asan-compact-rerun-2026-09-24/summary.json`）。以上によりM4のインターレース対応を採用する。M5と最終表示の検証は未了。Vulkan速度測定の一時的な停止・復号エラー、他GPU互換性、カメラ由来インターレース素材の未取得は制限として残す。
