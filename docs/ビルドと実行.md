# ビルドと実行

## 前提

Windows x64、**PowerShell 7**（`pwsh`）、MSVC C++ Build Tools、Windows SDKの`fxc.exe`、CMake、Python、GStreamer 1.28以降のMSVC x64ランタイムと開発SDKを用意する。GStreamer 1.28.2とDirect3D feature level 11_0のRTX 3070で検証した。VS2022／VS2026のCMake generatorをスクリプトが選択するが、実機ビルドの確認はVS2026で行った。

`bootstrap.ps1`は検査器用の固定FFmpeg SDKを取得・ハッシュ検証する。PATH上にある別版の`ffmpeg.exe`は画素参照に使わない。`proresd3d11dec`プラグイン自体はFFmpegやVulkanへリンクせず、実行時にもそれらへfallbackしない。bootstrapはGStreamerをインストールしない。

## ビルド

PowerShell 7でリポジトリのルートから実行する。

```powershell
./scripts/bootstrap.ps1
./scripts/build.ps1
```

GStreamerを既定のMSVC x64配置以外へ入れている場合は、`./scripts/build.ps1 -GStreamerRoot 'GSTREAMER_ROOT'`のようにインストール先を指定する。ビルド成果物は`build/vs18/plugins/Release/`に作られる。ディレクトリ名`vs18`はスクリプト上の固定名であり、選択したVisual Studioの版を意味しない。DX11 shaderはWindows SDKの`fxc.exe`で`cs_5_0`へ事前コンパイルされる。

## 現在のシェルで使う

```powershell
. ./scripts/use-d3d11-plugin.ps1
gst-inspect-1.0 proresd3d11dec
gst-inspect-1.0 proresd3d11rgb
```

GStreamerの配置を変更した場合は、設定スクリプトにも同じ`-GStreamerRoot`を渡す。このスクリプトは現在のPowerShellプロセスの`PATH`、`GST_PLUGIN_PATH`、`GST_REGISTRY`を設定するだけで、システム環境変数を書き換えない。GStreamerのbinを固定FFmpeg SDKのDLLで上書きしない。

```powershell
# D3D11Memoryで復号し、表示変換は行わない。
gst-launch-1.0 -e filesrc location=sample.mov ! qtdemux ! proresd3d11dec ! "video/x-raw(memory:D3D11Memory)" ! fakesink sync=false

# progressive・limited BT.709素材を専用Compute ShaderでRGBにして表示。
gst-launch-1.0 -e filesrc location=sample.mov ! qtdemux ! proresd3d11dec ! proresd3d11rgb ! d3d11videosink

# アルファ付き素材の標準AYUV64を標準sinkへ渡す。
gst-launch-1.0 -e filesrc location=sample.mov ! qtdemux ! proresd3d11dec ! "video/x-raw(memory:D3D11Memory),format=AYUV64" ! d3d11videosink
```

`sample.mov`は実際のProRes MOVへ置き換える。`proresd3d11rgb`はBT.709・progressive専用であり、インターレースの表示には別のデインターレース要素が必要。alphaなしのYUV出力をCPU側へ渡したい場合だけ、下流に`d3d11download`を明示する。

## 検査

固定SDKで合成素材を生成し、GStreamerのEOS／seek／D3D11Memoryを確認する最短手順は次のとおり。

```powershell
./scripts/generate-media.ps1
./scripts/test-d3d11-plugin.ps1 -OutDir build/local-smoke
```

全画素比較、性能測定、ASan変異、実表示QoSの条件と再現用コマンドは[検証](検証.md)を参照。検査スクリプトが使うFFmpegはリポジトリ内の固定SDKを明示指定する。出力は公開ソースに加えず、ローカルの`build/`以下を指定する。
