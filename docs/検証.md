# 検証

## 対象と方法

数値の対象はWindows上のGStreamer 1.28.2、NVIDIA RTX 3070でビルドしたDX11版。CPU画素基準にはリポジトリ内へ固定配置したFFmpeg 8.1 SDKを明示指定し、PATH上の別版は使わない。比較器だけが検証用にGPU画像を読み戻す。通常のデコーダー出力は`GstD3D11Memory`のままである。

- 圧縮packetを同じ入力からCPUとDX11へ渡し、VLDと逆スキャン後の係数を全件照合する。最終YUV画像は全画素・全成分を元深度の整数コードで比較する。Vulkan出力を正解値とはしない。
- アルファ付きはCPU参照の出力深度へ合わせて比較し、`AYUV64`の16bit詰めも確認する。アルファ16の元16bit値の下位6／4bitはFFmpegの10／12bit出力では失われるため、CPU出力だけでその下位bit一致は証明できない。
- 専用RGB要素は同じDX11 YUVから計算した独立BT.709式と全画素比較する。4:2:2のクロマ位置は左寄せとし、RGB10A2の最終丸め差を1 codeまで許容する。
- parserへ決定的な破損packet変異を投入し、MSVC AddressSanitizerで境界を検査する。GStreamerではEOS、flushing seek、バッファ保持、色・寸法・形式の途中変更、破損時の停止を確認する。
- 実表示のdecoder QoSは、通常QoS、`d3d11videosink`のPresent(0)、`sync=true`で、再生前に窓の可視・前面状態を確認して測る。最初の周回と窓状態が遷移した周回は除外し、decoder入力・出力PTSとQoS欠落を照合する。sink dropや表示間隔は別指標であり、OS/DWMの実表示はこの測定では証明しない。

## 確認済みの主な数値

| 項目 | 最終DX11版の結果 |
| --- | --- |
| 係数 | 10bit 422系11素材420枚、alphaなし拡張18素材780枚、alpha付き24条件48枚、インターレース等9素材362枚、端数寸法2素材4枚で不一致0 |
| CPU対DX11の全画素 | 上記のYUV最大差1 code。アルファはCPU出力深度で差0。色・寸法・形式の途中変更24枚も全件通過 |
| 独立BT.709式対専用RGB | 32素材1,859枚、R/G/B最大差1 RGB10A2 code |
| 公開HQ素材の連続復号 | 4素材779枚、D3D11Memory出力とEOSを確認 |
| parser変異 | 6種のseedから24,000件、MSVC AddressSanitizer検出なし |
| lifecycle | EOS×3、flushing seek×5、4種のインターレース、IDCT表更新直後の例外からのseek復帰を確認 |
| synthetic HQ direct出力 | RTX 3070で1080p約436 fps、4K約258 fps。GPU完了待ち・表示時刻は含まない |

実表示のdecoder QoSについては、このソース版の最終バイナリを用いた再測定値がまだない。従って現在の版の無欠落や実表示速度を数値で主張しない。他GPU、実際のdevice lost、HDR→RGBの数値精度、再配布条件が明確なカメラ由来のアルファ／インターレース素材も未検証である。D3D11 debug layerは検証環境に未導入で、debug layerのエラー0も主張しない。

## ローカルでの再現

PowerShell 7で依存物を用意・ビルドした後、合成素材を生成する。次の出力先はローカルの`build/`以下であり、公開物へ含めない。

```powershell
./scripts/bootstrap.ps1
./scripts/build.ps1
./scripts/generate-media.ps1
./scripts/test-d3d11-plugin.ps1 -OutDir build/local-smoke
python scripts/compare-d3d11-real.py media/synthetic-1080p60-hq.mov --mode yuv --frames 180 --streaming --out build/local-yuv.json
python scripts/compare-d3d11-real.py media/synthetic-1080p60-hq.mov --mode rgb_element_formula --frames 180 --streaming --out build/local-rgb.json
python scripts/benchmark-d3d11-plugin.py media/synthetic-1080p60-hq.mov media/synthetic-2160p60-hq.mov --modes dx11-direct --loops 3 --repeats 3 --out build/local-benchmark
```

色・端数寸法・途中変更の全画素検査には、`./scripts/probe-prores-feature-matrix.ps1 -OutDir build/local-feature-probe`で固定SDKの素材を生成した後、`python scripts/check-m5-dynamic.py --out build/local-dynamic.json`を使う。ASan検査は`scripts/test-d3d11-parser-mutations.ps1`を使い、固定SDKから取り出すseed MOVをローカルに用意する。公開カメラ素材はリポジトリに同梱しないため、それに依存する検査は利用者自身の適法な素材で再実行する。実表示の計測器は`scripts/benchmark-d3d11-display.py`、PTS・窓状態の集計器は`scripts/summarize-final-display.py`。計測中にウィンドウ状態を変えず、開始前の前面確認とウォームアップ除外を守る。
