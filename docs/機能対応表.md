# ProRes DX11 / FFmpeg Vulkan 機能対応表（M0）

更新日：2026-09-24。ここでいう「Vulkan成功」は固定SDK `tools/ffmpeg-n8.1-latest-win64-lgpl-shared-8.1/bin/ffmpeg.exe`（実版 `n8.1.3-20260921`）がRTX 3070を選び、`-hwaccel vulkan -hwaccel_output_format vulkan` のフレームを生成した実測を指す。静的35条件は各2フレームをGPUから`hwdownload`してframemd5まで完走した。動的2条件は`-noautoscale -c:v wrapped_avframe`で4/6フレームを通した。動的条件だけは画像readbackを行っていないため、後段で別途画素確認する。再現スクリプトと全件のFourCC、pix_fmt、色タグ、SHA256、成否は`../scripts/probe-prores-feature-matrix.ps1`、`../results/feature-matrix-2026-09-24/summary.json`。詳細ログは同結果ディレクトリに保存する。

根拠ソースはFFmpeg n8.1の[proresdec.c](https://github.com/FFmpeg/FFmpeg/blob/n8.1/libavcodec/proresdec.c)と[vulkan_prores.c](https://github.com/FFmpeg/FFmpeg/blob/n8.1/libavcodec/vulkan_prores.c)。前者はFourCCで10/12bitを決め、picture headerで422/444、alphaなし/8/16bit、progressive/TFF/BFF、色の3フィールドを読み、寸法・pix_fmt・field type変更時に出力形式を再取得する。後者は`sw_pix_fmt`のクロマ/深度、alpha、field順をシェーダへ渡す。したがって「422系FourCCは必ず422」「4444系FourCCは必ず444」は実装上の制約ではない。`prores_ks`で生成できる組合せだけに範囲を狭めない。

表記：`V2`はVulkan実測2/2枚、`V90`/`V120`はM2と同じ素材の90/120枚をVulkanで復号しGPU読戻しまで完了、`V4`/`V6`は動的4/4・6/6枚（画像読戻しなし）。`I10`=`I422_10LE`、`Y10`=`Y444_10LE`、`I12`=`I422_12LE`、`Y12`=`Y444_12LE`、`A16`=`AYUV64`。いずれも`video/x-raw(memory:D3D11Memory)`の`format`値。`A16`は10/12bit YUV+alphaを16bit packed容器へ出す設計候補で、画素配置・下流接続はM3で未検証。422/10bit/progressive/alphaなしの4行はM1コミット`7d67521`、alphaなしの444/12bit交差8行はM2コミット`f1e77c0`で採用。詳細は[422プロファイル拡張](422プロファイル拡張.md)と[444・12bit拡張](444・12bit拡張.md)。

## GStreamer 1.28.2 / RTX 3070 のD3D11Memory形式検査

`d3d11_memory_probe`を候補形式ごとに動かし、`gst_d3d11_device_get_format`、pool確保、全テクスチャのUAV作成を検査した。再現は`../scripts/probe-d3d11-output-formats.ps1`、結果は`../results/feature-matrix-2026-09-24/d3d11-formats.json`。この検査は確保・UAVだけで、色精度や標準sinkへの接続をまだ証明しない。

## 範囲と未達

上表の`V2`/`V90`/`V120`/`V4`/`V6`行をこのgoalの実装対象とする。ソース上で受理されるが有効fixture未作成の422+alphaは未判定であり、対象外にはしない。`alpha_info>2`とProRes header version>1は`proresdec.c`が事前に不正として拒否するため対象外候補だが、固定SDKでの負例確認とDX11の`STREAM/FORMAT`確認は未了。未知FourCCや他のbitstream境界もこの表だけで非対応と断定しない。

M0で判明した交差組合せ（422系FourCCの444/alpha、4444系FourCCの422）は、名目上のM1/M2だけでは漏れる。alphaなしの8条件はM2で採用し、alphaはM3で扱う。Vulkan出力は過去にCPUとの差があるため、DX11の画素基準にはせず、固定SDK CPUとの全画素・全プレーン比較を別に行う。M0/M1/M2は完了したが、alpha・interlace・周辺仕様・実表示は未達であり、goal全体を完成扱いにしない。
