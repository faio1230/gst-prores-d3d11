# 機能対応表

`proresd3d11dec`はProResをDirect3D 11 Compute Shaderで復号し、`video/x-raw(memory:D3D11Memory)`を出力する。以下はGStreamer 1.28.2／RTX 3070で確認した範囲であり、他GPUでの動作を保証しない。FourCCだけでクロマやアルファを決めず、picture headerも解析する。

| 入力 | 確認した範囲 | 出力形式 |
| --- | --- | --- |
| `apco`（Proxy）、`apcs`（LT）、`apcn`（Standard）、`apch`（HQ） | 10bit、4:2:2／4:4:4、alphaなし／8bit／16bit | alphaなしは`I422_10LE`／`Y444_10LE`。alpha付きは`AYUV64` |
| `ap4h`（4444）、`ap4x`（4444 XQ） | 12bit、4:2:2／4:4:4、alphaなし／8bit／16bit | alphaなしは`I422_12LE`／`Y444_12LE`。alpha付きは`AYUV64` |
| アルファ付き出力 | 8bit／16bit。4:2:2のU/Vは隣接画素へ複製して4:4:4へ展開 | 標準`AYUV64`（各成分を16bit全域へ詰める）。独自capsフィールドなし |
| フィールド | progressive、TFF、BFF。apch 4:2:2とap4h 4:4:4＋alpha16でTFF/BFFを全画素確認 | インターレースは`interlace-mode=interleaved`と`field-order`を設定 |
| 色タグ | BT.601、BT.709、BT.2020、PQ、HLGを確認。headerのmatrix 0／2はYUV用には未指定とし、利用可能なら入力capsを参照 | 標準`colorimetry`へ反映。復号画素はlimited range |
| 寸法 | 4:2:2の318×178、4:4:4の319×179を全画素確認。1080p／3840×2160も検証 | 4:2:2は偶数幅が必要。奇数幅なら`STREAM/FORMAT`で拒否 |
| 途中変更 | 色、寸法、`I422_12LE→Y444_12LE→AYUV64`を単一pipelineで確認 | 変更に応じて出力capsを再交渉 |

`proresd3d11rgb`はprogressive・limited BT.709のplanar 4:2:2／4:4:4から`RGB10A2_LE`へ、`AYUV64`から`RGBA64_LE`へGPU変換する。4:2:2の入力は左寄せ`chroma-site=mpeg2`を要求し、444では画素ごとのクロマを使う。インターレースとBT.709以外の色条件は暗黙変換せず拒否する。デインターレースや一般の色変換にはGStreamerの下流要素を使う。

CPU／Vulkanの復号への暗黙fallbackはない。通常の出力に画像のCPU読み戻しは含まれない。対応形式の設計は[設計](設計.md)、検証条件と数値は[検証](検証.md)を参照。
